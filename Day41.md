# 📡 4. Exploring Morse Code as a Communication System

Through this project, I explored Morse Code beyond just dots and dashes.

Topics covered:

- History of Morse Code
- Alphabet encoding
- Number encoding
- Timing principles
- Sending and receiving signals
- Emergency communication
- Speed improvement techniques

I learned how a simple binary communication system became one of the most important technologies in early global communication.
